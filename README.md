# الملاح — Mallah Navigator

تطبيق ملاحة عربي لأندرويد يعمل مع الإنترنت وبدونه، مع أدوات للعمل الميداني وقياس المساحات.

**من تصميم الأستاذ مصطفى سامي** — ‎+964 786 166 6400 · ‎+964 775 596 2400

## التنزيل
- **نسخة الويب (لابتوب و iPhone):** https://mustafasami446-star.github.io/mallah/ — في iPhone: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
- **التطبيق:** من قسم [Releases](../../releases) — ابحث عن أحدث إصدار يبدأ بـ `app-` ونزّل ملف `Mallah-Navigator.apk`.
- **خريطة العراق للعمل بدون إنترنت:** تُنزَّل من داخل التطبيق (القائمة ← الخرائط بدون إنترنت)، أو يدويًا من أحدث إصدار يبدأ بـ `map-` (ملف `mallah-iraq-map.zip`) ثم «تثبيت من ملف».

## كيف تتحدّث الخريطة
يجهّز GitHub Actions خريطة جديدة تلقائيًا كل ثلاثة أشهر (ويمكن تشغيله يدويًا من تبويب **Actions ← Build Iraq map pack ← Run workflow**). يتحقق التطبيق من `updates/map.json` ويعرض على المستخدم تنزيل التحديث.
